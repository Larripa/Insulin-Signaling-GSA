# GSA for Microglia Insulin Signaling Model

Global sensitivity analysis (Sobol method) of microglia insulin signaling model.

## Reproducing this analysis

1. Set up the environment:
   use ` environment.yml`

2. Run `insulin_signaling_GSA.ipynb`.

3. Outputs reproduce figures in the manuscript.

## Requirements
Run on the National Research Platform (NRP), JupyterHub, Python 3.11.15.
See `environment.yml` for exact pinned package versions
(key packages: SALib 1.5.2, numpy 2.4.3, numbalsoda 0.3.5, scipy 1.17.1).
